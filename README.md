Official reproducible code repository, trained model artifacts, and interactive forecasting web application accompanying:

> **Aygün, İ (2026).** *Bibliographic characteristics and journal context associated with early and five-year citation accumulation.*

## Repository Structure

```text
citation_trajectory_repo/
├── app.py                                      # Interactive Gradio app (deploy directly to Hugging Face Spaces)
├── requirements.txt                            # Python dependencies
├── README.md                                   # Documentation & reproducibility guide
├── model_artifacts/
│   └── trained_citation_models_v1.json         # Transparent, zero-leakage JSON weights (trained on OpenAlex probabilistic cohort <=2019 t0)
└── src/
    ├── run_q1_v2_clean_pipeline.py             # Main single-chain reproducibility pipeline (Tables 1-8, Clustered FE, Confusion Matrix)
    ├── run_q1_v3_advanced_experiments.py       # Out-of-time 2020->2021, Shapley/LMG R^2, Ke et al. (2015) B-index, 3-way FE
    ├── run_q1_v4_colab_validation.py           # Probabilistic reference sample (N=24,000) & 2022 external cohort (N=8,000) validation
    └── Colab_OpenAlex_Q1_Ek_Deneyler.py        # OpenAlex API harvesting script for probabilistic & historical t0 data
```

## Quick Start

### 1. Run Interactive Forecaster Locally (or Deploy to Hugging Face Spaces)
```bash
pip install -r requirements.txt
python app.py
```
To deploy on **Hugging Face Spaces**, create a new Gradio Space and upload `app.py`, `requirements.txt`, and `model_artifacts/trained_citation_models_v1.json`.

### 2. Reproduce All Manuscript Tables & Statistical Analyses
```bash
python src/run_q1_v2_clean_pipeline.py
python src/run_q1_v3_advanced_experiments.py
python src/run_q1_v4_colab_validation.py
```

## Responsible Use Disclaimer
In accordance with the **San Francisco Declaration on Research Assessment (DORA)** and the **Leiden Manifesto**, citation predictions generated by this tool reflect statistical expectations from historical OpenAlex records and must **never** be used as a substitute for expert peer review or as a direct measure of intrinsic scientific quality.
